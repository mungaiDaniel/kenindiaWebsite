## Important: about the wording
The website blocked full automatic copying, so most prose was captured as a faithful **summary**: headings, figures, lists, tables, names and links are exact, but long paragraphs are reworded and marked `content_status: extracted-not-verbatim` / `[paraphrase]`.
Exact copies: Motor Private, and close to exact for a few news posts.

**Before launch, get Kenindia's WordPress export** (WordPress admin → Tools → Export → All content). It contains every page and post word-for-word, plus all media. Your IDE can then replace the paraphrased text automatically.
